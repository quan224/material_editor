# 教案形态规则（2026-09-01 用户定）

旧模式（Claude 写教学版代码块 + 操作步骤）已废弃——产出的教案错误率过高，用户反复当审查员，学习被纠错淹没。

**新模式**：教案只做 UE 导读，三要素：
1. 用到 UE 的哪些部分（文件 + 行号 + 一句话说明）
2. 省略了 UE 的哪些部分（明确列出 + 一句话为什么）
3. UE 为什么这么写（设计意图）

没有教学版代码块、没有操作步骤、不指导怎么写。用户直接读 UE 源码写代码。

**Why**：Claude 凭印象写代码/教案错误率极高（2026-08 下旬多轮事故：LWC 规则编造、不存在的基类、命名乱起）；UE 源码是权威教材，导读只需事实查询（文件/行号/设计说明），无判断型内容，Claude 不会出错。

**How to apply**：
- 新导读放 `MaterialEditor/docs/ue-reading/`，从课 6 开始，按用户推进节奏逐课建
- 旧教案 23 份原地保留当历史参考，不删不改
- Claude 的角色：带路（列 UE 文件行号）、答疑（当场查源码）、机械活（grep/编译/提交）；不写代码、不设计结构
- 相关：[[omission-checklist]]（四条铁律仍全部适用）
