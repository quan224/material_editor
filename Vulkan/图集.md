```

│                                                              │
│    ▲ acquire                 present ▼                      │
│    │ (领一张空的)            (交一张画好的)                     │
│    │                              │                          │
│    │         ┌─── 回收复用 ←─────┘                          │
│    │         │                                                │
└────┼─────────┼────────────────────────────────────────────────┘
     │         │
     ▼         │
┌──── 每帧四步（课 16 预告）─────────────────────────────────────┐
│                                                              │
│  ① acquire    "给我一张空图"                                   │
│  ② 录制命令    bindPipeline → setViewport → draw(3)            │
```

- **GPC**（Graphics Processing Cluster）：大区块，包含光栅化引擎 + 多个 SM
- **SM**（Streaming Multiprocessor）：**着色器在这里跑**（最小的可编程计算单元）
- **L2 缓存**：所有 SM 共享，是显存的"缓冲带"
- **显示引擎**：接显示器输出（对应你的 presentQueue）
- **DMA 引擎**：纯数据搬运（对应你的 transfer 族）

## 二、SM 内部：着色器跑的地方

这是 GPU 的"CPU 核心"——一个 RTX 4070 Ti SUPER 有 7680 个 CUDA 核心，分布在 60 个 SM 里。

```
┌──────────────────────── 一个 SM ─────────────────────────┐
│                                                           │
│  ┌───────────── 指令 / 调度 ─────────────┐              │
│  │                                        │              │
│  │   ┌──────┐   ┌──────┐   ┌──────┐    │              │
│  │   │Warp  │   │Warp  │   │Warp  │    │              │
│  │   │调度器│   │调度器│   │调度器│    │  ← 谁下一个跑  │
│  │   └──┬───┘   └──┬───┘   └──┬───┘    │              │
│  │      │          │          │         │              │
│  └──────┼──────────┼──────────┼─────────┘              │
│         │          │          │                         │
│         ▼          ▼          ▼                         │
│  ┌─────────────────────────────────────────────┐       │
│  │           寄存器文件（256 KB）                 │       │
│  │                                              │       │
│  │  一个 Warp（32 个线程）同时读各自寄存器         │       │
│  │  → 你 shader 里的 float4 position 就住这里    │       │
│  │  → 每个线程有自己的寄存器组（不共享）           │       │
│  │  → 速度：~10 TB/s（比显存快 20 倍）           │       │
│  └─────────────────────────────────────────────┘       │
│         │                                                │
│         ▼                                                │
│  ┌──────────────── 运算单元 ─────────────────┐          │
│  │                                            │          │
│  │   ┌────┐ ┌────┐ ┌────┐ ┌────┐           │          │
│  │   │FP32│ │FP32│ │FP32│ │FP32│  ×4 分区   │          │
│  │   │××16│ │××16│ │××16│ │××16│            │          │
│  │   └────┘ └────┘ └────┘ └────┘            │          │
│  │    ↑ 每分区 16 个 float32 CUDA 核心        │          │
│  │    = 64 个 FP32 核心/SM                    │          │
│  │                                            │          │
│  │   ┌────┐ ┌────┐         ┌────┐            │          │
│  │   │RT  │ │RT  │         │Tensor│  ×4      │          │
│  │   │核心│ │核心│         │核心  │           │          │
│  │   └────┘ └────┘         └────┘            │          │
│  │    ↑ 光线追踪            ↑ AI/矩阵         │          │
│  └─────────────────────────────────────────────┘         │
│         │                                                │
│         ▼                                                │
│  ┌──────────────── 共享内存 / L1 ─────────────┐         │
│  │                                            │         │
│  │  128 KB                                    │         │
│  │  → 同一个 Warp 内的 32 个线程可以共享       │         │
│  │  → 你 shader 里的 groupshared 变量住这里    │         │
│  │  → 比 L2 快，比寄存器慢                     │         │
│  └─────────────────────────────────────────────┘        │
│                                                         │
│  ┌────────── 纹理单元（Texture Unit）──────────┐        │
│  │                                            │        │
│  │  → vkCmdBindTextureSampler 绑的纹理在这读   │        │
│  │  → 采样/过滤/ mip 查找全硬件完成            │        │
│  └─────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────┘
```

**你的顶点/片元着色器就是在这里跑的**：
- 每个 SM 同时运行 ~2048 个线程（64 Warps × 32 线程/Warp）
- 一个三角形 3 个顶点 = 3 个顶点着色器线程（一个 Warp 的零头）
- 一个 800×600 三角形 ≈ 240,000 个片元 = 洒到几十个 SM 上并行

## 四、显存层级：速度 vs 容量

```
速度                                         容量
快 ↑                                         大 ↑
   │
   │  ┌─────────────┐
   │  │ 寄存器       │   256 KB / SM × 60 SM = ~15 MB 总量
   │  │ ~10 TB/s    │   每个线程私有，shader 局部变量住这
   │  └──────┬──────┘
   │         │
   │  ┌──────▼──────┐
   │  │ 共享内存/L1  │   128 KB / SM × 60 = ~7.5 MB
   │  │ ~5 TB/s     │   Warp 内共享，compute shader 用
   │  └──────┬──────┘
   │         │
   │  ┌──────▼──────┐
   │  │ L2 缓存     │   48 MB（全 GPU 共享）
   │  │ ~2 TB/s     │   所有 SM 共享，纹理/顶点数据经过这
   │  └──────┬──────┘
   │         │
   │  ┌──────▼──────┐
   │  │ GDDR6X 显存  │   12 GB
   │  │ 504 GB/s    │   纹理/顶点缓冲/cbuffer 全住这
   │  └──────┬──────┘
   │         │
   │  ┌──────▼──────┐
   │  │ PCIe 4.0    │   理论 32 GB/s（CPU 内存 ↔ GPU）
   │  │ ~25 GB/s    │   你的 readFile→vkCreateShaderModule→
   │  │             │   字节码上传走的这条路
   │  └─────────────┘
   │
慢 ↓                                         小 ↓
```

**速度差 200 倍**——这就是为什么 shader 编译要优化（少访问显存多算）、为什么 UE5 要做渲染管线优化（减少 PCIe 传输）。
