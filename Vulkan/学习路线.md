# Vulkan 学习支线

> 项目主线渲染后端是 DX12（课 14–17），Vulkan 只作了解对照。
> 本目录独立于 material_editor_project，不进主项目构建。

## 环境搭建（本机 = LunarG SDK 路线）

本机没有 MSYS2（那是另一台机器），且要求与主项目 vcpkg 完全分离：

1. **LunarG SDK**：https://vulkan.lunarg.com/sdk/home → Windows 最新版安装器（headers/loader/验证层/glslangValidator/vkcube 全家，装好自动配 `VK_SDK_PATH`）。驱动已验证：RTX 4070 Ti SUPER，Vulkan 1.4.351
2. **GLFW**：`thirdparty/glfw/` 已放好官方 3.4 预编译包（lib-vc2022），构建直接指路径，不碰 vcpkg
3. 验证：SDK 装完后 `where glslangValidator` 能找到、vkcube 能转；然后
   `cmake -B build -S .` + `cmake --build build --config Debug`（在 01_triangle/ 下，MSVC 生成器）

## 环境搭建（另一台机器 = MSYS2）

```bash
pacman -S mingw-w64-x86_64-vulkan-headers mingw-w64-x86_64-vulkan-loader mingw-w64-x86_64-glfw
```

- loader 是纯 C API，MinGW 链 vulkan-1 无问题；显卡驱动自带 Vulkan runtime
- 验证：`pkg-config --modversion vulkan` 能出版本号即通
- 以后需要抓帧再装 LunarG SDK / RenderDoc

## 学习路线

1. **vulkan-tutorial.com** —— 主线教程，约 30 小节，从 instance 讲到帧循环同步，
   就是"画三角形 1000 行"的完整拆解（地位 ≈ DX12 的 Frank Luna）
2. **SaschaWillems/Vulkan**（见 官方文档.txt）—— 教程啃完后按主题对照：
   顶点缓冲 → 深度缓冲 → 纹理 → UBO
