1. 五层金字塔 —— 自下而上依赖

L1 · 基础工具层（Core）
文件：Core/Public/{UUID.h, Logger.h, Singleton.h, MathTypes.h}
内容：UUID 生成、日志、单例模板、Vec2/3/4 数学类型
为什么存在：所有人都要用的"零依赖"工具，连反射都依赖它
L2 · 数据模型层（MaterialGraph）
文件：MaterialGraph/Public/{Types.h, Node.h, Pin.h, Graph.h, NodeFactory.h, GraphCompiler.h}
内容：节点/引脚/连接的"数据结构"（不是 UI），类型枚举 EValueType
为什么存在：把"图"这个概念独立出来，UI 和编译器都能用同一份
L3 · 反射系统（Reflection）
文件：Reflection/Public/{Reflection.h, ReflectionMacros.h}
内容：FieldDesc / ClassDesc / Registry / Accessor / ME_* 宏
为什么存在：让 UI 和序列化"不认识具体子类也能枚举/读/写字段"
L4 · 表达式层（Expression）
文件：Expression/Public/Expression.h, Expression/Private/Expression.cpp
内容：表达式抽象基类（4 个纯虚 + 3 个反射驱动 API），具体子类 ExprAdd / ExprConstant 等
为什么存在：每种运算（Add、Mul、Constant...）一个子类，统一接口
L5 · 应用层（UI / Compiler / Renderer）
文件：UI/、Compiler/、Renderer/
内容：Qt 节点图界面、HLSL 编译器、DX12 渲染器
为什么存在：用户最终看到的、用到的、跑起来的东西
每一层只能引用下方层，不能引用上方层。这就是为什么 Types.h 不能出现 HLSL 字符串（HLSL 在 L5），Reflection.h 不能出现 Expression（Expression 在 L4）。
