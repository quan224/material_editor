# F03 扩展调研笔记 — 次表面散射（生产级做法 + 精确常量）

> 补足参考实现（6 高斯代表性 profile + 均匀采样 + lerp 细节保持 + 无透射）之外的生产级知识。

## 关键发现

### 1. "可分离性"的数学根源（不是拍脑袋）
- 2D BSSRDF 卷积核 `R(r)` 本身**数学不可分离**；但 Zaragoza 团队对其矩阵做特征值分解发现：**第一特征值承载 ~80% 能量** + 扩散剖面**圆对称** → 可用 1D `s[x]` 做 `S[x,y] ≈ s[x]·sᵀ[y]` 近似，把 2D 卷积拆成两次 1D（横向+纵向）。d'Eon 的 6 高斯（12 次 1D 卷积）压到 2 次，1080p 1.05ms。
- 来源：Zaragoza 技术报告 https://graphics.unizar.es/papers/s4_techreport12.pdf ｜ Jimenez 2015 https://www.iryoku.com/separable-sss/

### 2. iryoku 开源实现的真实常量（直接抄，别自己造）
- **预设非均匀对称 kernel**（25/17/11 samples，**17 是行业默认**），RGB=权重、A=偏移。
- **中心样本 = `(0.536343, 0.624624, 0.748867)`**——强烈红色偏置（红色散射距离最长、保留能量最多），**这是"皮肤感"的物理来源**。我用的代表性值偏弱。
- **最外圈几乎只有 R 通道**有值（G/B≈1e-5、1e-7）——"红长程、蓝短程"烤进常量。
- 偏移是非均匀分布（外稀内密），**不是均匀对称**——我用的均匀采样外围能量浪费、中心欠采样。
- `calculateKernel` = 用最小二乘从 d'Eon 偶极子采样**拟合** N 个高斯；demo 本身就是 fitting 工具（CTRL+C 复制 `float4 kernel[]`）。
- 来源：https://github.com/iryoku/separable-sss/blob/master/SeparableSSS.h

### 3. Pre-integrated Skin（Penner 2011）— 另一条便宜路线
- 洞察：SSS 只在**光照变化或曲率变化**处可见（均匀光照平面卷积结果=原图）。
- 做法：把扩散剖面×辐照度对球面积分，预烘焙成 **2D LUT，轴=(N·L, 曲率 1/r)**，运行时一次纹理采样即可。三段处理：大曲率/小细节(对 R/G/B 不同 mip bias 采法线)/阴影半影。
- Simon's blog 给了**完全替代 LUT 的解析拟合**。
- 取舍：比 SSSS **便宜得多（无 blur pass，forward 单像素内完成）**，但更糙——依赖曲率图（蒙皮变形失效）、薄表面另做。
- 来源：http://advances.realtimerendering.com/s2011/（Penner PPTX）｜ http://simonstechblog.blogspot.com/2015/02/pre-integrated-skin-shading.html

### 4. Burley Normalized Diffusion（UE5 方向）
- `R(r) = A·s/(8πr)·(exp(-sr) + exp(-sr/3))`，其中 **A=反照率、d=散射距离（s=1/d）**——艺术家直觉参数，无需逆推单散射系数。
- **CDF 解析可逆**（zero-radiance 推翻了原论文"不可逆"），importance-sampling 无需牛顿迭代。
- **UE5 SubsurfaceProfile** = separable SSS 框架 + 可选 Burley kernel；GBuffer **Metallic 槽复用为 SubsurfaceProfile ID（≤255 个）**；`Opacity`=SSS mask；**已知短板："no backscatter of light"**（耳朵透红官方承认做不到，要靠透射 pass）。Burley 模式**要求 TAA 开启**。
- 来源：https://media.disneyanimation.com/uploads/production/publication_asset/153/asset/siggraph2016SSS.pdf ｜ https://dev.epicgames.com/documentation/unreal-engine/subsurface-profile-shading-model-in-unreal-engine

### 5. RE Engine Fast SSSSS（和 UE5/iryoku 不同的工程化）
- SSS **全在 compute 队列**：GBuffer 的 `VelocityXYAoSss.A`=SSS mask（同一 RT 还打包 velocity+AO）→ compute 把散射结果写进 `SubSurfaceParam (R32_UINT)` 全屏 RT。
- 然后 **Fast SSSSS Apply**（fragment，紧跟延迟光照后）：Step A 合成到新 diffuse buffer，Step B 与延迟 specular 合成。
- 思路：**把贵的 17-tap gather 移到 compute（mask 限定），fragment 只做合成**——SSSS 论文提过这条 fast 路径，RE Engine 工程化最彻底。
- 来源：https://mamoniem.com/behind-the-pretty-frames-resident-evil/

### 6. 透射/背光（屏幕空间做不到，必须独立 pass）
- 耳廓透红：光从头**另一侧**穿过薄板出来——背面像素没被光栅化到屏幕，纯 SSSS 物理上无法产生。
- 经典做法（iryoku `SSSSSTransmittance`，基于 Jimenez 2010 Translucency）：**用 shadow map 测厚度**（光空间当前点 z − shadow map z）×lightFarPlane → 喂 6 高斯透射剖面（**常量和反射核不同**）→ ×`(0.3 + dot(light,-N))` wrap lighting。
- 精确 6 高斯透射常量（直接抄）：`{0.233,0.455,0.649}exp(-d²/0.0064) + {0.1,0.336,0.344}exp(/0.0484) + {0.118,0.198,0}exp(/0.187) + {0.113,0.007,0.007}exp(/0.567) + {0.358,0.004,0}exp(/1.99) + {0.078,0,0}exp(/7.41)`。
- 无 shadow map 退化方案：预烘焙 **thickness map**（Substance/xNormal 生成），运行时 `d=thicknessTex.r*scale`。
- 来源：https://github.com/iryoku/separable-sss/blob/master/SeparableSSS.h ｜ https://www.iryoku.com/translucency/ ｜ https://therealmjp.github.io/posts/sss-intro/

## 对我参考实现的具体改进（按性价比）

| 优先级 | 改进 | 收益 |
|---|---|---|
| ★★★ | **常量直接抄 iryoku 17-sample**（中心红偏置 0.536/0.624/0.748） | 立刻有"皮肤感"，这是物理来源 |
| ★★★ | **加 transmission pass**（shadow map 测厚度 + 上面 6 高斯透射常量） | 视觉收益最大，耳朵/鼻尖"活过来" |
| ★★ | **均匀采样 → iryoku 非均匀偏移**（外稀内密） | 边缘红漏光更自然、banding 减少 |
| ★★ | **细节保持 lerp → 深度感知双边**（`300·distToProjWin·sssWidth·|Δdepth|`），绑 depth RT | 不抹掉真实红漏光，只防穿几何 |
| ★ | profile 换 **Burley 解析**（A=baseColor, d=scatterDist，免拟合） | 切换零成本，UE5 方向 |
| ★ | 学 RE Engine **mask 走 GBuffer A 通道 + compute 预备/fragment 合成** | 延迟管线性能更优 |
