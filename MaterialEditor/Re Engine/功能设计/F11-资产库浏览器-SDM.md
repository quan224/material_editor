# F11 — 资产库浏览器（SDM）

> 编辑器一个 dock 面板，浏览/搜索/预览材质库、贴图、模型，拖拽应用到当前图。借鉴 RE Engine 的 Scene Data Manager。
> 类别：B 引擎工程。**执行序第 11**：独立于渲染主线，按兴趣做。

## 1. 目标与动机

**变成什么功能**：一个资产浏览器 dock——分类（材质/贴图/模型）、搜索、缩略图预览、拖拽到节点图/预览。

**为什么不是 toy**：
- 材质编辑器**本来就要管理一堆材质资产**，没有浏览器就只能手打开文件路径。
- SDM 是 RE Engine 管 AAA 规模资产的范式，缩小到本项目就是一个实用的资产库面板。

## 3. 架构改动（逐层）

**资产层（L2/L5）**
- **统一资产引用**：材质/贴图/模型都走一套 `GUID + 路径 + metadata + 类型`，跨图引用稳定（避免断链）。
- **缩略图生成**：材质预渲染缩略图（后台/惰性，不卡 UI）。
- **索引/搜索**：按名称/tag/类型建索引。

**UI 层（课 13）**
- dock 浏览器：树/网格视图，分类 tab（材质/贴图/模型），搜索框。
- **拖拽**：贴图拖到采样节点、材质拖到预览、模型拖到场景。
- 与课 18 打通：保存材质自动进库。

## 5. 里程碑

- **M1 统一资产引用 + 目录扫描建索引**。
- **M2 材质缩略图生成**（惰性）。
- **M3 dock 浏览器 UI + 分类/搜索**。
- **M4 拖拽应用 + 与课 18 保存打通**。

## 6. 验收标准

- 能浏览/搜索库里的材质、贴图、模型。
- 材质保存后自动出现在库里（课 18 打通）。
- 拖拽贴图到节点、材质到预览能生效。

## 7. 诚实说明

- **缩略图生成必须后台/惰性**，否则卡 UI。
- **项目规模小**时不需要 RE Engine 级（上万资产）索引；先做轻量目录扫描版，量大再上数据库索引。
- 这是"用起来舒服"的功能，优先级可排在渲染特性之后。
