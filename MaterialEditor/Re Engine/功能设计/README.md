## 为什么是这个顺序（依赖 DAG）

底线：**地基先行、范式先行**。

```
F01(显存基建) ─┬─→ F04(RT) ─────→ F09(路径追踪)
F02(Profiler) ─┘      │
                      └─→ F08(Meshlet) ←── F07(摄影测量/重资产)
F03(SSS范式) ──┬─→ F05(头发)
               └─→ F06(眼睛)
F10(DPGI)        独立（只依赖课17）
F11(资产库)      独立（只依赖课13/18/21）
```

- **F01–F02 渲染器地基**：显存基建 + 性能可视。任何渲染优化（F04/F08）都靠它们测量，必须最先。
- **F03 材质范式**：SSS 打通"特殊材质类型→编译器→G-Buffer→面板"，F05/F06 套它。
- **F04 渲染路径范式**：RT 打通"可切换渲染后端"，F09 路径追踪在其上。
- **F07→F08 性能弧**：摄影测量提供重资产 → 喂给 meshlet 优化（用 F02 量化）。
- **F10/F11 独立**：动态 GI 和资产库不阻塞主线，排最后按兴趣做。

## 跨功能协同弧

- **性能优化弧**：`F07 重资产 → 课21加载 → F08 meshlet 优化 → F02 量化`
- **特殊材质范式**：`F03 SSS / F05 头发 / F06 眼睛`（共用"新材质模板→编译器→G-Buffer→面板"管线）
- **可切换渲染路径**：`F04 RT / F09 路径追踪 / 经典光栅`（共用材质描述、靠开关切后端）

## 设计文档统一模板（每份 F0x 含 7 节）

1. **目标与动机** — 变成什么功能、为什么不是 toy
2. **涉及课次与文件** — 嵌在项目的哪（课次 + 模块/文件）+ 前置依赖
3. **架构改动** — 按本项目分层（节点图 / 编译器 / 渲染器 / 资产 / UI）逐层说
4. **RE Engine 资料对应** — 哪份演讲/文章对应哪一步（链接见 01–05）
5. **里程碑** — M1/M2… 渐进可验证
6. **验收标准** — 能量化、能演示
7. **诚实说明** — 硬件前提、已知局限、复杂度边界

## 设计原则（贯穿所有 F0x）

- **不是读论文，是做功能**：每个 F0x 最终要在编辑器里产生一个用户能用的、可演示的特性。
- **复用项目已有范式**：材质参数走反射（`ME_FIELD`）、节点走 `Expression`、HLSL 走 `MaterialCompiler`、UI 走 Qt 面板——新功能尽量长在现有骨架上。
- **每步可验证**：里程碑都要能用 Profiler（F02）或肉眼看到效果。
- **诚实标注硬件/复杂度边界**：RT 要 RTX20+、mesh shader 要 DX12 Ultimate 等，写在文档里。
