# F09 — 路径追踪参考 / 烘焙模式

> 编辑器一个"Bake Reference"模式，对当前材质用路径追踪**离线/准实时**渲染一张 ground-truth 高质量图，作为材质效果的参考基准。
> 类别：A 渲染进阶。**执行序第 9**：依赖 F04 的 DXR 地基。**最重的 F0x。**

## 1. 目标与动机

**变成什么功能**：材质编辑器的预览旁边加"参考渲染"——用路径追踪出一张物理正确的图，让材质师校准光栅/RT 预览到底准不准。

**为什么不是 toy**：
- 材质师**需要 ground-truth 参考**来判断光栅预览是否正确——材质工作流的真实刚需。
- RE Engine 自己在 Requiem/Pragmata 把 PT 做成了功能，证明它在材质/渲染管线里有真实位置。
- 路径追踪**概念上比光栅更简单**（统一光传输，不用 shadow/SSR/GI 一堆 hack）；overkill 的只是"实时"——本功能刻意做成**离线/累积收敛**的参考模式，绕开实时性的工程大山。

## 3. 架构改动（逐层）

**渲染器层（第三条路径）**
- 路径追踪器：raygen → 全程弹射 + 俄罗斯轮盘截断 + **NEE（自发光直接光照）** + **ReSTIR GI**（间接光重采样，降噪用）。
- 降噪：M3 用自研 SVGF；有 NVIDIA RTX Kit 时接 **DLSS Ray Reconstruction**。
- **SER**（Shader Execution Reordering）优化光追 hit 一致性。
- **ScreenSpaceAlphaTest**：cutout 几何在 PT 下投软阴影的轻量方法。
- 共用材质描述：PT/RT/光栅 三条路径读同一套材质属性——RE Engine 强调"PT 暴露光栅掩盖的资产缺陷"，材质必须统一。

**UI 层**
- "Bake Reference"按钮 + 采样数/时长参数 + 结果窗口，与光栅/RT 预览**并排对比**。

## 5. 里程碑

- **M1 参考 PT（无降噪）**：1 spp 逐帧累积，靠时间收敛，纯离线——最简单的起步，不碰 ReSTIR/降噪。
- **M2 NEE + ReSTIR GI**：自发光直接光 + 间接光重采样，收敛更快。
- **M3 降噪**：先自研 SVGF；有 SDK 再换 DLSS RR。
- **M4 Bake 按钮 + 并排对比**：与光栅/RT（F04）预览并排，差异可分析。

## 6. 验收标准

- 能对同一材质出一张 PT 参考图，随采样累积噪点减少、收敛。
- 与光栅/RT 预览并排，能看出光栅哪里偷工（如 SSR 屏外断裂、阴影过硬）。
- 三条路径共用材质，结果可对照。

## 7. 诚实说明

- **最重的 F0x**。ReSTIR + 降噪是研究生级，M1→M4 跨度大，慢慢来。
- **要 RT 硬件**。M1 参考 PT（纯累积）是最务实起点，不需要降噪先有结果。
- **资产质量**：PT 暴露法线/材质/几何缺陷，测试资产要好（接 F07 写实资产）。
- **不是预览主路径**：它是"参考/烘焙"，日常预览仍走光栅/RT（F04）。别把它当实时主渲染。
